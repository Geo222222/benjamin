# Benjamin Public Disclosure

Benjamin has no automatic path from private capital activity to the public Little Book.

A public proof must be deliberately created for a defined verifier and purpose. The proof should disclose the smallest claim that satisfies that purpose and should reference a Big Book commitment rather than reveal the private record.

Examples:

```text
AUTHORITY CLAIM
Subject: X
Entity: Martin Capital LLC
Authority: Treasury Signatory
Valid: YES
Expires: 2027-09-01
Evidence commitment: ...
Big Book state commitment: ...
```

or:

```text
ASSET CLAIM
Entity: Martin Institution
Asset claim: 0x91A7...
Authority valid: YES
Evidence commitment: ...
Big Book state commitment: ...
```

A public verifier does not receive the portfolio, investment thesis, transaction amount, counterparty record, investor list, family ledger, or source contract unless that separate disclosure is independently authorized.
